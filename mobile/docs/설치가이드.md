# 친비즈 모바일 앱 설치 가이드 (회원용)

친비즈 워크스페이스는 **앱(PWA)** 으로 설치해서 쓸 수 있습니다.
설치하면 홈 화면 아이콘으로 바로 실행되고, **공지·정산·영업 등 알림을 휴대폰 알림으로** 받을 수 있습니다.

> 지금은 **안드로이드(Chrome)** 를 우선 지원합니다. (아이폰은 추후 지원)

## 설치 방법 (안드로이드 · Chrome)

1. 크롬(Chrome) 브라우저로 **`https://admin.chinbiz.kr`** 접속
2. 로그인
3. 주소창 옆 **⋮ (더보기)** → **[앱 설치]** 또는 **[홈 화면에 추가]** 선택
   - 또는 하단/상단에 뜨는 **"앱 설치"** 안내를 누릅니다.
4. 홈 화면에 **친비즈** 아이콘이 생깁니다. 이 아이콘으로 실행하세요.

## 알림 켜기

1. 앱을 실행하고 로그인합니다.
2. 우측 하단 **🔔 알림 켜기** 버튼을 누릅니다.
3. 브라우저가 묻는 **알림 허용**에서 **허용**을 선택합니다.
4. 끝! 이제 나에게 오는 공지·업무 알림이 **앱이 꺼져 있어도** 휴대폰 알림으로 도착합니다.

- 알림을 탭하면 관련 화면(내 워크스페이스)으로 바로 이동합니다.
- 알림을 끄려면: 휴대폰 **설정 → 앱 → 친비즈(또는 Chrome 사이트 설정) → 알림** 에서 끌 수 있습니다.

## 자주 묻는 질문

- **앱을 새로 설치해야 업데이트되나요?** 아니요. 웹이 바뀌면 앱도 자동으로 최신 화면이 됩니다.
- **여러 기기에서 쓸 수 있나요?** 네. 폰·태블릿 각각에서 설치·알림 허용하면 모두로 알림이 갑니다.
- **알림이 안 와요.** ① 알림 허용을 눌렀는지 ② 휴대폰 설정에서 앱 알림이 켜져 있는지 ③ 인터넷 연결을 확인하세요.
