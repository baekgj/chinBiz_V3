각각의 모든 admin에 공동으로 적용되는 사항
화면이나 메뉴를 만들경우 각각 모듈화를 하여 제작할것 
제작된 모듈 소스의 위치를 제작note파일에 기록할 것

파트너admin, 본부admin, 센터admin, 버즈(매니저)admin 에 공통으로 적용되는 사항
상단의 메뉴를 클릭할 경우, 해당 메뉴화면으로 이동하여야 한다.(대시보드 map 이동 아님)
상단 오른쪽의 업체명 클릭시 내정보수정 화면으로 이동
- 전화번호, 이메일, 담당자명, 계좌정보(은행명, 계좌번호, 예금주명), 비밀번호 변경 가능해야함

파트너admin의 상품관리 메뉴에 오른쪽 상단에 상품등록 버튼을 만들고
클릭시 상품등록화면을 구현하는데 본사admin의 상품등록화면을 참조해서 만들어줘

본사admin, 파트너사admin의 상품등록화면에서 상품설명은 edit 기능을 추가해줘







파트너admin의 영업관리메뉴
1. 등록일자, 고객명(전체), 영업내역(버튼생성), 거래확정(버튼생성)
2. 상품명 클릭시 상품 상세내역 보여지게
3. 고객명 클릭시 고객정보 화면 보여지게
4. 영업내역 버튼 클릭시  버즈/매니저 admin의 영업관리 메뉴에서 맨니저가 등록한 영업사항을 볼수 있도록 화면 구현
5. 거래확정 버튼 클릭시 해당 영업
