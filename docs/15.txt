본사admin의 [시스템설정]메뉴에 [약관설정] 소매뉴를 생성하고, 
[약관설정]화면에서 다음의 10가지의 약관정보를 등록,수정 할수 있도록 기능을 구현해줘
1. 통합이용약관
   - /docs/agree_total_20270727.docx 파일을 읽어서 통합이용약관으로 저장하고, home하단의 [법적고지]의 [이용약관]을 클릭할 때 화면을 보여줘
2. 개인정보처리방침
   - /docs/agree_personal_20270727.docx 파일을 읽어서 개인정보처리방침으로 저장하고, home하단의 [법적고지]의 [개인정보처리방침]을 클릭할 때 화면을 보여줘
3. 버즈회원 이용약관
  - /docs/agree_buzz_20270727.docx 파일을 읽어서 버즈회원이용약관으로 저장하고, home의 회원가입 화면에서 (필수)이용약관 동의의 [보기]를 클릭할 경우 화면을 보여줘
4. 관리매니저 이용약관
  - /docs/agree_manager_20270727.docx 파일을 읽어서 관리매니저이용약관으로 저장하고, 버즈admin에서 [버즈 네트워크]메뉴에서 [매니저신청하기]버튼을 클릭할 경우, 관매니저 이용약관을 보여주고, 동의함을 체크하도록 만들어줘
5. 센터 이용약관
   - /docs/agree_center_20270727.docx 파일을 읽어서 센터 이용약관로 저장해줘
     화면구성은 나중에 다시 요청할께
6. 본부 이용약관
   - 현재 파일이 없으니, 나중에 내용을 등록할 수 있는 기능만 만들어줘
     화면구성은 나중에 다시 요청할께
7. 센터 위수탁계약서
   - /docs/paper_center_20270727.docx 파일을 읽어서 센터 위수탁계약서로 저장해줘
     화면구성은 나중에 다시 요청할께
8. 본부 위수탁계약서
   - /docs/agree_hq_20270727.docx 파일을 읽어서 본부 위수탁계약서로 저장해줘
     화면구성은 나중에 다시 요청할께
9. 파트너 이용약관
   - /docs/agree_partner_20270727.docx 파일을 읽어서 파트너 이용약관으로 저장해줘
     화면구성은 나중에 다시 요청할께
10. 개인정보 수집·이용 동의
   - /docs/agree_personal.txt 파일을 읽어서 개인정보 수집·이용 동의에 저장하고,
    home의 [회원가입]화면의 [(필수) 개인정보 수집·이용 동의]의 [보기]버튼 클릭하는 경우와 home의 [파트너사 입점신청]화면의 [필수] 개인정보 수집·이용에 동의합니다. [동의서 보기] 버튼을 클릭하는 경우, 화면이 나오도록 작업해줘
