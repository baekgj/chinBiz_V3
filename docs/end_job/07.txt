매니저admin을 다음사항에 맞도록 수정해줘
1. user.role가 MANAGER이더라도 admin은 버즈admin으로 동일하게 로그인 되어야 해
2. 버즈admin에서 user.role이 MANAGER 인 경우 상단 메뉴오른쪽에  [매니저admin보기] 버튼을 생성해 주고
해당 메뉴를 클릭하면 매니저admin 으로 이동하게 해줘
3. 마찮가지로 매니저admin 상단 오른쪽에 [버즈admin보기] 클릭하면 버즈admin으로 돌아오도록 해줘


회원가입시
1. Home에서 회원가입할때 추천인이 있으면 sales_center_id는 추천인id의 user.sales_center_id를 넣어주고, 추천인이 없으면 입력하는 주소의 시/구/군값을 추출해서 center_code의 값을 체크해서 idx값을 넣도록 수정해 줘
2. 센터admin, 버즈adimin에서 회원 가입시 sales_center_id는 로그인 회원id의 user.sales_center_id값이 자동으로 들어가도록 수정해 줘


본사, 파트너사 admin의 상품등록시 
상품의 계약종료기간을 칼렌더로 선택할수 있도록 해주고, 설치상품여부를 체크박스로 선택할수 있도록 db의 상품테이블에 저장해줘


모든 각 admin에서
1. 상품마켓의 상품리스트에서 계약종료일자가 등록된 상품은 상품이미지 오른쪽 상단에 D-O일로 표시해줘
2. 계약종료일자가 7일 미만남은 경우, 상품명 하단에 붉은색으로 [영업마감일 O일 남았습니다.]표시해줘


버즈admin에서
1. 계약종료일자가 7일이상 남은 경우 
[상세보기] 버튼 옆에 [1차영업신청] 버튼을 생성하고, 버튼을 클릭할 경우 1차영업신청 화면을 띄워줘
   이때 상품의 카테고리와 상품명은 자동으로 선택되게 해줘
2. [상세보기] 버튼을 클릭하여, 상품상세보기 화면으로 들어가면 계약종료일자가 7일이상 남은 경우 [1차영업신청]버튼을 우측상단과 우측하단에 생성해 주고, 버튼을 클릭하면 1차영업신청 화면을 띄워줘
이때 상품의 카테고리와 상품명은 자동으로 선택되게 해줘
3. 영업등록시 상품을 선택하는 경우 계약종료일자가 7일이상 남은 상품들만 선택가능하게 해줘
4. user.role이 BUZZ인 경우 [버즈 네트워크] 메뉴 화면에서 상단 타이틀(버즈 네트워크) 오른쪽 위치에 [매니저신청하기] 버튼을 생성해 주고, 클릭시 매니저신청하기 화면을 띄워줘
5. user테이블에 manager_status(CHAR(1)), manager_code(VARCHAR(20)), manager_center_id(bigint), manager_sdate(VARCHAR(10)), manager_edate(VARCHAR(20)) 필드를 추가해줘
manager_status는 기본값 N이고, 신청접수시 I, 신청승인시 Y 값이야.
6. 매니저신청하기 화면은 지역본부 선택, 센터를 선택할 수 있도록 해 주고, 신청하기 버튼을 클릭하면 user테이블의 manager_center_id, manager_sdate, manager_status=I 필드에 저장해줘


매니저admin에서
1. [관리영업 파이프라인] 메뉴를 [영업관리] 메뉴로 수정해주고 소메뉴로 [버즈1차접수현황],[2차영업관리]메뉴를 생성해줘
2. [버즈1차접수현황]에서는 버즈의 user.sales_center_id = 로그인 매니저의 user.manager_center_id이 같은 1차영업신청 건중에 아직 매니저가 선정되지 않은 리스트가 나타나야 하고, 우측에는 [배정받기](기존의 우선할당) 버튼이 나와야 함
3. [2차영업관리] 화면에서는 배정받은 영업신청 리스트가 표시되어야 함
