파트너admin에서
영업관리메뉴에서 [구매확정] 버튼 클릭시 fixed_date, fixed_month 필드는 업데이트 되지 않도록 수정해줘

버즈admin, 매니점admin 의 상품상세보기 화면의 상품설명 란에, 다음과 같은 내용을 표시해줘 
설치제품여부 : 본 제품은 설치 및 교육대상 상품입니다.
단순배송상품여부 : 본 제품은 배송상품이며, 설치나 교육이 진행되지 않습니다.
취소시 매니저 보전비 있음 : 설치후 주문취소시 영업보전비 0000원 지급되는 상품입니다.

본사admin에서
1. 추천인들의 tree구조에서 특정 버즈회원의 센터코드를 변경하면, 
tree구조에서 해당 버즈회원을 추천으로 등록한 버즈회원들을 모두 센터코드가 변경되도록 작업을 하고 싶어
예를 들어, 
홍길동1(강남센터) -- 홍길동2 -- 홍길동3 -- 홍길동4 -- 홍길동5 -- 홍길동6
                                                                |
                                                           홍길동41
                                                                |
                                                           홍길동42

위와 같이 강남센터 소속의 홍길동1의 추천을 받아 가입된 버즈회원들은 모두 홍길동1의 소속센터로 설정되는데
만약, 홍길동3의 소속센터를 제주센터로 변경할 경우, 홍길동3을 최초 추천 등록한 모든 회원들(홍길동4~6, 홍길동41,42)를
모두 홍길동3의 소속센터로 변경되도록 기능을 구현해줘
[회원정보 수정]화면에 [하위추천회원 소속센터 전체변경]버튼을 만들고, 버튼을 클릭하면,
변경할 센터를 선택할수 있는 화면을 보여주고, [일괄변경] 버튼을 클릭하면 일괄변경되도록 작업해줘


2. [수당및정산관리] 메뉴에 [매출현황],[마감내역],[정산내역],[지급내역] 소매뉴를 생성
1) 매출현황 메뉴: 
    (1) 상단 검색영역 : 대상월 선택
        수당테이블(allowance)에서 confirm_date = 검색월, status=MP, paid=0, fixed_month=null 인 내역을 sale테이블과 join하여 아래 리스트로 보여줘. 
        리스트는 paging 처리하지 말고, 화면을 넘어가지 않게 스크롤바를 적용해줘 
        (영업등록일, 주문번호, 회원유형, 회원id, 수당type, 수당금액, 확정일자) 
     (2) 리스트 하단 오른쪽에 [마감완료]버튼을 생성하고, [마감완료] 버튼 클릭시 해당 내역들의 fixed_date=오늘일자, fixed_month=마감월 로 업데이트 해줘
        
   2) 마감내역 메뉴 :  
    (1) 상단 검색영역 : 대상월 선택
        수당테이블(allowance)에서 fixed_month = 검색월, paid=0 인 내역을 회원유형과 회원id의 합산금액으로 보여줘
        리스트는 paging 처리하지 말고, 화면을 넘어가지 않게 스크롤바를 적용해줘 
        (회원유형, 회원id, 수당금액) 
    (2) 리스트 하단 오른쪽에 [정산완료]버튼을 생성하고, [정산완료]버튼 클릭시 해당 내역들의 paid=1로 update하고, allowance_payment 테이블에 삽입해줘

   3) 정산내역 메뉴 :  
    (1) 상단 검색영역 : 대상월 선택
        수당지급테이블(allowance_payment)에서 fixed_month = 검색월, payment_flag = N 인 내역을 user테이블과 join하여 보여줘
        리스트는 paging 처리하지 말고, 화면을 넘어가지 않게 스크롤바를 적용해줘 
        (회원유형, 회원id, 은행명, 계좌번호, 예금주, 지급금액) 
    (2) 리스트 하단 오른쪽에 [지급완료]버튼을 생성하고,  [지급완료]버튼 클릭시 해당 내역들의 payment_flag=Y, payment_date = 오늘날자 update해줘

   3) 지급내역 메뉴 :  
    (1) 상단 검색영역 : 대상월 선택
        수당지급테이블(allowance_payment)에서 fixed_month = 검색월, payment_flag = Y 인 내역을 user테이블과 join하여 보여줘
        리스트는 paging 처리하지 말고, 화면을 넘어가지 않게 스크롤바를 적용해줘 
        (회원유형, 회원id, 은행명, 계좌번호, 예금주, 지급금액, 지급일자) 



본사admin의 [수당및 정산관리] 메뉴의 
[매출현황], [마감내역], [정산금액], [지급내역]메뉴의 화면구성을 아래와 같이 통일해줘
1. 대상월, 검색버튼은 리스트 상단 오른쪽으로 이동
2. 합계금액, 대상건수는 리스트 상단 외쪽에 표시
