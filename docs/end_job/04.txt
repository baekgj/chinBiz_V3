본사admin의 메뉴구성

좌측의 [상품관리] 메뉴 아래의 다음의 소메뉴를 만든다.
- 카테고리 관리, 상품등록, 상품리스트

1) 카테고리관리  : 
    - 카테고리리스트 오른쪽 상단에 [카테고리 등록]버튼을 만든다.
   - 카테고리 리스트는 category 테이블에 등록된 대/중/소분류여부, 카테고리명, 운영상태를 보여주고, 게시/중지 버튼을 만든다.
     게시/중지 버튼 클릭시 운영상태값을 변경한다.
   - 카테고리 등록 버튼 클릭시  대/중/소 분류를 선택하고, 카테고리명을 입력하는 화면은 만든다.
   - 카테고리 명을 클릭시 카테고리 수정화면을 보여준다.
2) 상품등록 : 
   - 상품등록화면은 아래의 상품정보를 입력받아야 한다.
     상품명, 수당유형(비율:RATE/고정:FIXED), 판매가, 총수당
     카테고리선택, 파트너사 선택, 상품이미지(5개)
    역할별 수당(버즈회원, 상위추천회원, 매니저, 소속센터, 관리센터, 총괄본부, 본사)
    상품설명(editer 기능)
   설치규정, 반품/취소규정, 판매여부
3) 상품리스트(현재의 상품관리 화면) 
   - 현재 상품리스트의 좌측 영역을 60%늘리고, 총수당 분배 시뮬레이터는 40%로 줄이기  
   - 상품리스트 하단에는 페이징 기능 추가
   - 상품리스트 상단에는 카테고리 선택, 파트너사 선택, 판매여부 선택, 상품명 검색 기능 추가
   - 상품명 클릭시 오른쪽의 총수당분배 시뮬레이터가 변경되는것은 그대로 유지
   - 상품정보수정 버튼(작게) 클릭시 등록한 상품정보 수정화면 보이도록 작업



좌측의 [조직망관리] 메뉴 아래의 다음의 소메뉴를 만든다.
- 본부·센터 등록, 회원리스트, 조직관리

1) [본부·센터 등록] 메뉴 클릭시 본부·센터 회원가입 화면이 나타난다.
    회원가입 화면은 아래의 정보를 입력받아야 한다.
    역할(본부/센터) , 아이디, 중복확인버튼, 비밀번호, 이름, 전화번호, 이메일, 은행명, 계좌번호, 예금주
    - 역할에서 본부를 선택한 경우 : center_code테이블에서 center_code = null인 값을 리스트에 보여주고 선택할수 있도록 한다.
    - 역할에서 센터를 선택한 경우 : 광역본부user테이블에 등록되어 있는 본부list를 보여주고 선택할수 있도록 하고, 광역본부를 선택하면 user.sales_center_id = center_code.idx 인 head_code 값을 가져와서 center_code.head_code 가 같고, center_code <> null인 리스트를 보여주고 선택할수 있도록 한다.

2) 회원리스트
   - 등록된 회원의 리스트를 보여준다.
   - 회원명 클릭시 회원정보 수정화면을 보여준다.  비밀번호 변경도 가능해야 한다.

3) 조직관리(현재화면)
   - 본부·센터 트리 화면에서 본부명, 센터명을 클릭하면, 트리구조의 버즈, 매니저 구조가 나타나야 한다.


상단 오른쪽의 업체명 클릭시 내정보수정 화면으로 이동
- 전화번호, 이메일, 담당자명, 계좌정보(은행명, 계좌번호, 예금주명), 비밀번호 변경 가능



2. 본부/센터 계정은 user 테이블에 저장,     저장시 center_code.idx값을 sales_center_id에 저장
1.center_code 테이블에서 center_code값이 null이면 본부후보이고, null이 아니면 센터 후보임
  즉, 센터를 등록하려면 선택한 본부의 user.sales_center_id값을 가져와서 center_code.head_code 값을 찾고,
다시 이 값을 center_code값이 null이 아닌 데이터들을 찾아서 센터리스트에 뿌려주는 것임
3. 등록한 센터의 idx값은 user.sales_center_id 값에 저장




본사admin에서
카테고리 등록시 중분류/소분류를 선택할때 어떤 대분류/중분류 안에 들어가는 카테고리인지 선택할수 있게 해줘

상품등록시 이미지는 5개 고정으로 등록하는것이 아니라, 한개씩 추가해서 최대 5개까지만 등록할수 있도록 수정해줘

수당유형이 고정인 경우, 총수당 = 역할별 수당의 합이 일치하지 않은면 메세지 표시 후 저장 불가
수당유형이 비율인 경우, 역할별 수당의 합 = 100이 아니면 메세지 표시 후 저장 불가

본사admin에서
카테고리등록시 소분류를 선택하면, 대분류, 중분류를 선택할수 있도록 해줘
상품등록시 카테고리 선택도 대분류 선택하면 중분류가 나오고, 중분류를 선택하면 소분류가 나오도록 해줘
상품 이미지 등록의 경우 이미지url를 입력하는 방식이 아니라, 파일을 업로드하거나, 이미지 파일을 드레그 해서 업로드 하도록 수정해줘
