본사admin에서 상품등록시 상품설명 등록 필드를 다음과 같이 분리해줘
[비 로그인 전용 / 버즈회원 전용 / 매니저회원  전용 / 파트너 전용 / 관리자  전용] 으로 등록할수 있도록 해줘
-비로그인 전용 : 차후 개발시 적용 예정
-버즈회원 전용 : 버즈admin의 [상품마켓]메뉴의 [상세보기]클릭시 나오는 상품의 상세정보에 등록된 버즈회원용 상품설명이 보여지도록
-매니저회원 전용 : 매니저admin의 [관리마켓]메뉴의 [상세보기] 클릭시 나오는 상품의 상세정보에 등록된 매니저회원용 상품설명이 보여지도록
-파트너 전용 : 파트너admin의 [상품관리]메뉴의 [상품수정] 화면에서 나오는 상품의 상세정보에 등록된 파트너전용 상품설명이 보여지도록

상품 상세설명의 editer를 좀더 기능이 많은 editer로 변경해줘


본사admin의 [시스템설정]-[환경설정]화면에 [추천마일리지 지급] 섹션카드를 생성하고, 
[추천인 id 등록시 버즈회원 (500) CP, 추천ID회원 (500) CP 지급] 입력 필드를 생성해줘

home의 회원가입시 추천인 id를 등록하는 경우, 추천인id와 가입한 버즈회원 모두에게 본사admin의 [시스템설정]-[환경설정]-[추천마일리지 지급]에서 설정된 버즈회원, 추천인 회원 CP를 지급해줘. 만약, 추천인 id를 입력하지 않았거나, 입력한 추천인 id가 존재하지 않을 경우, 추천인 id를 강제로 dukebaek 으로 지정하고, 모두 cp를 지급해줘 
이 경우 allowance의 order_no = join_가입일자_시분초, type = JOIN, status = CP 으로 INSERT 해줘

버즈admin에서 [1차 영업등록] 버튼을 클릭해서, 1차 영업등록이 완료될 때
allowance의 type = JOIN, status = CP 가 있을 경우, 해당 건은 MP로 변경해줘
