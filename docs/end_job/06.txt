버즈admin

네트워크 메뉴
내 버즈네트워크 리스트는 가입일, 아이디, 회원명, 역할, 상태 표시
- 회원명 클릭시 회원정보 수정화면
회원등록버튼 클릭시 회원등록 화면 -> 저장시 추천인이 자동으로 저장
회원리스트 검색기능 (아이디/이름), 가입일자(시작~종료) 검색
- 가입일자 검색을 칼렌더 기능 추가
리스트 하단에는 paging 처리

회원등록/수정화면
입력데이터 : 아이디, 중복확인버튼, 비밀번호, 이름, 핸드폰번호, 이메일, 우편번호(우편번호 검색버튼), 기본주소, 상세주소, 정산계좌(은행명, 계좌번호,예금주명)
- 회원가입시 역할은 버즈로 고정, 추천인 자동 저장


상품마켓 메뉴
한페이지당 3 x 3 개씩 보여주기
하단에 paging 처리
- 상품명 클릭시 상품상세화면을 볼수있도록 화면
상품리스트 검색기능(상품명, 파트너사), 카테고리 검색


영업파이프라인 메뉴
[1차 영업등록] 버튼 추가
 - [1차영업등록] 버튼 클릭시 영업등록화면 
   카테고리 선택, 상품선택, 고객기본정보(상호명, 사업자등록번호, 대표자명, 회사전화번호, 담당자명, 핸드폰번호, 이메일, 회사주소(우편번호 검색), 회사 상세주소, 영업진행상태, 메모  등록할수 있어야 하고 저장시
상품번호, 버즈 id, 매니저id 저장필드도 있어야 함
영업리스트에는 등록일, 상품명, 파트너사명, 고객명(전체이름), 1차영업자명, 영업단계(상태) 보이도록 작업
- 상품명 클릭시 상품상세화면을 보이도록 작업 하되, 수당내역은 버즈인경우 버즈, 추천인 수당만 보이게, 매니저인 경우 매니저, 버즈, 추천인 수당만 보이도록 작업
- 고객명 클릭시 1차 영업등록 정보를 보이도록 작업


버즈admin, 매니저admin에서
상품마켓의 상품리스트에 수당금액이 맞지 않음.
비율인 경우 총수당금액에서 비율을 계산해서 보여줘
상품상세화면에서 총수당금액을 보이지 않게 해줘
상품상세화면에서 돌아가기 버튼 추가해줘
