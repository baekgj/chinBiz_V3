매니저admin과 센터admin, 파트너admin에 회비와 입점비를 결제할수 있는 메뉴를 구현할거야
먼저, 본사admin의 [시스템설정] 메뉴에 [관리비설정]메뉴를 생성하고,
[관리비설정]에서 각 회원에 대한 관리비 금액을 아래와 같이 설정할수 있도록 화면을 구현해줘
- 매니저회원 : 월회비 : (    )원,  연회비 (     )원
- 센터회원 :  월회비 : (    )원,  연회비 (     )원
- 파트너 : 입점비 (    )원




매니저/센터/파트너ADMIN에 결제 메뉴를 만들어줘
매니저/센터 회원은 결제 메뉴에서 월회비/연회비를 선택할수 있어야 하고, 선택된 회비 종류에 따라 결제 금액이 변경되야 해
파트너 회원은 입점비 한 종류만 선택할 수 있어야 해
결제방식은 신용카드/가상계좌/계좌이체/간편결제 를 선택할 수 있도록 하고, 마지막에 MP수당 결제를 추가해줘
MP수당 결제를 선택할 경우 결제금액은 부가세를 제외한 금액이 나타나도록 해줘

매니저와 센터회원은 user테이블에 해당 회원의 회원만기일자 필드를 추가하고, 파트너 회원은 partner 테이블에 해당 파트너의 입점비 납부여부 필드와 납부일자 필드를 추가해줘
매니저/센터 회원은 회원만기일자가 지났을 경우, 결제 메뉴만 접속되도록 해줘.  다른 메뉴를 선택하더라도 결제 메뉴로 이동되도록 하고, 회비 납부가 완료되면 회원만기일자가 UPDATE 되면(회원만기일자가 오늘보다 남아 있으면) 다른 메뉴를 사용할 수 있도록 해줘

파트너회원은 입점비 납부가 되었으면, ADMIN 메뉴를 사용할수 있지만, 입점비가 미납이면
결제 메뉴로 이동해서 입점비 결제를 진행하도록 해줘

토스 sdk 연동 골격 미리 만들어줘


회원정보의 주민등록번호가 입력되어 있는 회원인 경우,
결제내역에서 가상계좌/계좌이체 결제시 회원정보의 주민등록번호가 입력되어 있는 경우 세금계산서 버튼을, 없으면 현금영수증 버튼을 생성하고, 버튼 클릭시  토스페이먼트로 api를 호출하여 세금계산서 or 현금영수증 신고 할수 있도록해줘
결제창 전달 방식으로 바꿔줘


매니저/센터/파트너admin의 결제내역 리스트의 가로 넓이를 넓혀줘

매니저회원의 결제화면에서 회비 금액이 0원으로 나오는 오류를 확인해줘


결제화면에서 결제방식에 간편결제를 삭제하고, 네이버페이/카카오페이 를 추가해주고
토스페이먼트에 연동해줘


본사admin의 [수당및정산관리]메뉴에 [회비결제내역] 메뉴를 추가하고, 
회비 및 입점비 결제내역 리스트를 아래 내용에 맞게 만들어줘
1. 상단 : 검색기능
    - 결제일~결제일, 
    - 대상-전체/매니저/센터/파트너
    - 결제방법 : 전체/신용카드/가상계좌/계좌이체/네이버페이/카카오페이/MP
    - 구분 : 전체/월회비/연회비/입점비
    - 검색어 입력 및 검색 버튼
2. 중간 : 결제내역 리스트
    - 결제일자, 회원유형, 회원ID(회원명), 구분, 결제수단, 결제금액, 만기일자, 현금영수증
3. 하단 : 페이징

본사 ADMIN의 [수당및정산관리]-[회비결제내역]화면의 결제일을 칼렌더 선택 가능하게 해줘
회비 결제내역이 한건도 나타나지 않는데 쿼리 확인해줘



매니저/센터ADMIN의 결제화면에서 MP수당 선택하여 결제 진행시 allowance 테이블에 회비결제 내역을 아래와 같이 추가해줘
(type=MEMBERSHIP, amount=-금액, status=MP, fixed_date=결제일)


매니저/센터admin의 [수당현황] 화면에서 type = MEMBERSHIP 인경우, [회비결제]로 표시
