본사ADMIN에서
상품등록화면에서 설치상품여부 옆에 아래의 항목을 추가해줘
1. 단순배송상품 여부
2. [취소시 매니저 보전비 있음] 체크 추가
3. 매너저보전비 있음을 체크할 경우 취소비용cancel_amount 입력값 추가 하고 product 테이블에 추가해줘
  
파트너사admin 에서
[영업현황]에서  해당 상품이 [설치상품]이고, 진행상태가 배송/설치, 구매확정 일때, [취소]버튼을 클릭하는 경우,
매니저에게 영업보전비 50000원을 지급하는 프로세스를 다음과 같이 변경해줘
상품구분 : [설치상품] 체크된 경우 -> [매니저보전비 있음] 체크된 상품인 경우
진행상태 : 동일(배송/설치, 구매확정)
영업보전비 : 50000원 -> 상품테이블의 취소비용(cancel_amount)
위와 같이 프로세스를 변경 후, 테스트를 진행해주고, 테스트한 데이터는 삭제하지 말아줘


본부admin에서
1. 대시보드 화면에서 [산하 센터별 본부 수당 기여도 랭킹 보기 ›] 버튼을 [본부 실시간 정산 및 광역 자산 현황판] 카드섹션 아래로 이동시켜줘
2. [본부 정산 수당 기여도 요약] 카드섹션은 삭제해줘

버즈admin에서
1. 대시보드의 MP확정수당 카드섹션 하단의 [출금신청][출금가능] 버튼을 삭제하고, [확정된 MP수당은 익월 정산됩니다.] 문구 추가
2. 대시보드 화면은 버즈ADMIN의 로고영역에 링크를 걸어줘
3. [수당현황]메뉴를 [수당/정산현황]으로 변경하고, [수당현황][정산현황]메뉴를 소매뉴로 추가해줘
   - 수당현황 화면 : 
      1) 상단 검색영역 : 구분(전체, 영업수당, 추천수당), 상태(전체, 예정, 확정), 대상월을 검색버튼 추가
      2) 대상 리스트 : 수당테이블(allowance)에서  member_id=버즈회원id, member_type=구분검색값:BUZZ(영업수당)/TOPBUZZ(추천수당), status =상태검색값(예정:CP,확정:MP),  fixed_month = 검색월
          (영업일자, 구분, 상품명, 고객명, 추천버즈회원, 확정일자, 수당금액, 상태) 
   - 정산현황 화면 : 
      1) 상단 검색영역 : 대상월을 검색버튼 추가
      2) 대상 리스트 : 정산테이블(allowance_payment)에서  member_id=버즈회원id, member_type=BUZZ/TOPBUZZ, status =MP,  fixed_month = 검색월
          (대상월, 구분, 정산금액, 지급일자) 

4. 대시보드의 수당구성을 아래와 같이 db 적용해줘
1)직접영업CP : 수당테이블(allowance)에서 member_id=버즈회원id, created_at가 현재월, member_type=BUZZ, staatus =CP 인 합
해당 금액 클릭시 [수당/정산현황]-[수당현황]에서 이번달, 구분=영업수당, 상태=예정 으로 링크 

2)추천 네트워크 : CP : 수당테이블(allowance)에서  member_id=버즈회원id, created_at가 현재월, member_type=TOPBUZZ, staatus =CP 인 합
해당 금액 클릭시 [수당/정산현황]-[수당현황]에서 이번달, 구분=추천수당, 상태=예정 으로 링크 
 
3)이번달 확정MP : 수당테이블(allowance)에서  member_id=버즈회원id, created_at가 현재월, member_type=BUZZ,TOPBUZZ, status =MP 인 합
해당 금액 클릭시 [수당/정산현황]-[수당현황]에서 이번달, 구분=전체, 상태=확정 으로 링크

4)누적 확정MP : 정산테이블(allowance_payment)에서  member_id=버즈회원id,member_type=BUZZ,TOPBUZZ
   해당 금액 클릭시 [수당/정산현황]-[수당현황]에서 월검색 없이 전체 내역 보이도록 링크
