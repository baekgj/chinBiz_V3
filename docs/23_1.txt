1. 매니저admin의 대시보드에서 [관리매니저 활동 가이드] 옆에 동그라미물음표 버튼을 넣어주고
동그라미물음표 버튼을 클릭하면 [관리매니저 핵심 활동 가이드 (4-Step)] 레이어 창을 나올수 있도록 수정해줘
 - [관리매니저 활동 가이드] 접기/열기 버튼은 [접기] 버튼을 클릭시 해당 섹션 카드의 내용이 보이지 않도록 하고,
   [열기] 버튼을 클릭하면, 해댕 섹션의 내용이 보이도록 해줘

2. 매니저admin의 대시보드에서 [진행 중인 2차 영업 관리] 섹션에서 
[상담대기 → 방문/실사 → 계약보조 → 최종성공 → 정산완료]의 단계를 가운데 맞춤으로 수정해줘
- 버즈admin의  대시보드에서 [영업 파이프라인 현황] 섹션에서 의 5단계도 가운데 맞춤으로 수정해줘

3. 모바일에서 접속시 매니저admin의 대시보드에서 [진행 중인 2차 영업 관리] 섹션에서 [실사 리포트 및 사진 작성하기] 버튼 클릭시 핸드폰의 카메라가 켜질수 있도록 해줘
   pc에서 접속시  [실사 리포트 및 사진 작성하기] 버튼은 보이지 않게 해줘
